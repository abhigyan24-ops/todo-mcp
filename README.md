# Todo-v2

Todo-v2 is a simple web-based todo list application built with vanilla HTML, CSS, and JavaScript. It serves as a starting point for a more feature-rich todo app.

## Project Structure

- `index.html` – Entry point of the web app.
- `style.css` – Global styling.
- `app.js` – JavaScript logic (placeholder).
- `assets/` – Folder for images, fonts, or other static assets.
- `.gitignore` – Excludes `node_modules` and build artifacts.

## Run Instructions

1. **Open in Browser**  
   Simply open `index.html` in a modern web browser (Chrome, Firefox, Edge, Safari). No server is required for this minimal demo.
